# PGK–Erscheinungswelt: Forschungsvergleich v0.2

Diese Sammlung eröffnet eine **offene, hypothesengeleitete Gegenüberstellung** der formalen PGK-Forschung und dokumentierter Beobachtungen sowie Methoden aus anderen Forschungsgebieten.

Sie setzt auf dem PGK-Forschungssnapshot `62b917f8304e00eaac4ad0d71c6f31986adf4c56cc2e0920f163d764a2c4e0e1` auf. Die 590 Registerzuordnungen umfassen **191 Forschungsbefunde, 317 Claims, 29 Module, 19 Nachweisprofile und 34 thematische Beziehungen**. Eine Zuordnung ist ein *Recherchevorschlag*, nicht der Nachweis einer empirischen PGK-Entsprechung.

## Forschungsgrundsatz

- Theoretische Hypothesen, negative Resultate und fundierte Schätzungen werden ausdrücklich bewahrt.
- Ähnlichkeit wird nicht mit Messgleichheit verwechselt. Wo die nötige Operationalisierung fehlt, bleibt diese Lücke sichtbar.
- Eine formale PGK-Wahrheit im definierten Modell verlangt nicht notwendig eine Naturanalogie; ihr physikalischer Zusatzanspruch würde aber eine solche Brücke benötigen.
- Die externen Fachquellen sind eigenständige empirische oder mathematische Ergebnisse. Sie bestätigen nicht den PGK-Mechanismus.
